# Books Directory Hierarchy (1std to 12thd)

Strict structural arrangement requested:
```
books/
└── <Class> (1std to 12thd)

            └── <Units> (Unit and their names, or "Unit" if no name)
                └── <Chapters> (Chapter Name)
                    └── <Topics> (Topic Name)
                        └── topic_info.txt
```
