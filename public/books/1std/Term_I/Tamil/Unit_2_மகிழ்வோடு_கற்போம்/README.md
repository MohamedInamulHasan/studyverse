# Unit_2_மகிழ்வோடு_கற்போம்
**Class**: 1std | **Term**: Term_I | **Subject**: Tamil

### Topics:
1. **அணிலும் ஆலமரமும்** - அ, ஆ எழுத்துக்கள் அறிவோம்
2. **இனிப்பும் ஈயும்** - இ, ஈ எழுத்துக்கள் அறிவோம்
3. **உரலும் ஊஞ்சலும்** - உ, ஊ எழுத்துக்கள் அறிவோம்
4. **எலியும் ஏணியும்** - எ, ஏ எழுத்துக்கள் அறிவோம்
5. **ஐயமும் ஐப்பசியும்** - ஐ எழுத்து அறிவோம்
6. **ஒட்டகமும் ஓணானும்** - ஒ, ஓ, ஔ மற்றும் ஃ எழுத்துக்கள் அறிவோம்
